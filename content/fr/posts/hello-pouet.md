Premier article. Trois choses à savoir :

1. Les articles vivent dans `content/en/posts/` et `content/fr/posts/`. Chaque traduction est son propre fichier ou bundle ; Hugo les associe par chemin.
2. `hugo server -D` lance le site en local avec les brouillons.
3. Les deux articles d'exemple sont faits pour être supprimés.

```bash
hugo new content/fr/posts/mon-premier-vrai-article/index.md
```

C'est tout. À vous d'écrire.
