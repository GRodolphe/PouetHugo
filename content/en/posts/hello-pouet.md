First post. Three things worth knowing:

1. Posts live in `content/en/posts/` and `content/fr/posts/`. Each translation is its own file or bundle; Hugo pairs them by path.
2. `hugo server -D` runs the site locally with drafts on.
3. Both sample posts are meant to be deleted.

```bash
hugo new content/en/posts/my-first-real-post/index.md
```

That's it. Go write.
