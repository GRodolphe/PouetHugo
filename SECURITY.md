# Security policy

## Reporting a vulnerability

Please report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/GRodolphe/PouetHugo/security/advisories/new) on this repository. You should get a first response within a week.

## Release provenance (SLSA Build Level 3)

Every release tag publishes a source archive with [SLSA v1.0 Build Level 3](https://slsa.dev/spec/v1.0/levels) provenance, generated by the isolated, reusable [slsa-github-generator](https://github.com/slsa-framework/slsa-github-generator) workflow. The provenance file (`*.intoto.jsonl`) is attached to the GitHub release next to the archive.

To verify an archive before using it:

```bash
# https://github.com/slsa-framework/slsa-verifier
slsa-verifier verify-artifact pouethugo-v1.0.0.tar.gz \
  --provenance-path pouethugo-v1.0.0.tar.gz.intoto.jsonl \
  --source-uri github.com/GRodolphe/PouetHugo \
  --source-tag v1.0.0
```

A valid result proves the archive was built by this repository's release workflow on GitHub-hosted runners from the stated tag, and was not tampered with afterwards.

## Scope notes for template users

- The template ships no server-side code; the attack surface of a deployed site is your host plus the runtime origins listed in [docs/features.md](docs/features.md) (Google Fonts, jsdelivr at pinned versions, and analytics only if you enable it).
- `markup.goldmark.renderer.unsafe = true` allows raw HTML in markdown. That is safe while you are the only author; reconsider it if untrusted contributors can commit content.
